---
title: Video and stills
description: Video file and still image inputs
---

Still and Video inputs keep the file path and the rest of their settings in the session. The mixer loads that file when it is present on disk.

When the file is missing, the Input stays in the session as Invalid. Path, crop, audio, and playback settings stay as stored. Opening a session lists those Inputs. Relink from folder… searches the directories you pick; a filename that appears once is written back onto that Input. A name that is missing or appears more than once keeps the stored path. Choose file… sets one Still or Video Input to a specific file (double-click a row in the missing-file dialog). Show in Explorer (Finder on macOS) opens the stored file or its folder.

GUI Load Last opens the most recent existing session file as the current document. Opening an export (`.eivzx`) asks for a media extract folder and a working `.eivz` path.
