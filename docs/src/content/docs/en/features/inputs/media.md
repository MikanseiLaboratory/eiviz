---
title: Video and stills
description: Video file and still image inputs
---

Still and Video inputs keep the file path and the rest of their settings in the session. The mixer loads that file when it is present on disk.

When the file is missing, the Input stays in the session as Invalid. Path, crop, audio, and playback settings stay as stored. Relink media… on the Input list searches the directories you pick. A filename that appears once is written back onto that Input. A name that is missing or appears more than once keeps the stored path.

GUI Load Last opens the most recent existing session file as the current document.
