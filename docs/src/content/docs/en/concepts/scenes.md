# Scenes

A Scene is Inputs stacked as layers. In [Input → Scene → Output](/concepts/inputs/), this is where the picture is built.

Add one from Scenes. Edit sets each layer’s position, size, opacity, and order.

Use it on Mixing Unit Preview/Program, as an Overlay, on a Multiview, or as an Output source.
