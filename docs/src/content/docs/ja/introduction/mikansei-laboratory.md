eivizの開発・保守運営を行う研究開発コミュニティです。  
[FlowingSPDG](https://github.com/FlowingSPDG)/河村 柊吾が主宰を務めており、eivizのリードエンジニアを担当しています。  
eiviz上で行っているOMT送受信・エンコード/デコード処理やvMix互換APIは、未完成成果物研究所が公開しているクレートを使って実装しています。
