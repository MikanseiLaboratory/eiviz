eivizの開発・保守運営を行う研究開発コミュニティです。  
[FlowingSPDG](https://github.com/FlowingSPDG)/河村 柊吾が主宰を務め、eivizのリードエンジニアを担当しています。  
eivizにおけるOMTの送受信やエンコード/デコード処理、vMix互換APIは、未完成成果物研究所が公開しているクレートを用いて実装されています。
