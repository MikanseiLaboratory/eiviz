# eiviz

このサイトでは、使い方、開発目的、現場での運用までをまとめています。

- [eivizについて](/introduction/about/) — 開発動機と技術選定
- [システム要件](/introduction/requirements/) — 対応環境とハードウェア
- [システムアーキテクチャ](/introduction/architecture/) — Mixer と UI の構成
