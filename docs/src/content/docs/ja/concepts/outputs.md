title: Outputs

Outputは、Mixing UnitのProgram本線や各種ソース（Input、Scene、Multiview等）をネットワーク（NDI/OMT）へ外部送出するための機能です。

## 設定とルーティング

[設定](/eiviz/ja/introduction/settings/)ウィンドウの「出力」から設定します。

- **転送プロトコル**: OMTまたはNDIに対応しています（DeckLink等のハードウェア出力は現在実装中）。
- **映像ソース**: Input、Scene、MU Preview、MU Program、Multiviewから選択できます。
- **音声ソース**: Mixing UnitのMU Bus、またはNone（音声なし）を指定します（Multiview選択時は音声なし固定）。
- **解像度・フレームレート**: 出力系統ごとに個別に設定可能です。「セッション設定を使用」を選んだ場合はセッション共通設定に従います。

## クロック管理と独立スレッド

各Outputは、合成エンジンと共通の有理数メディアクロックに同期してフレームを送出します。

- **独立スレッド構成**: 各出力系統には専用のスレッドが割り当てられ、特定の出力でエンコード遅延やネットワーク負荷が発生しても、他の出力や本線の映像合成に影響を与えません。
- **フレームレート変換**: ソースより出力フレームレートが高い場合は最新フレームの再送、低い場合は適切な間引き処理を自動で行います。
- **エンコード効率**: 1つのOutputに対して複数のクライアントが接続した場合でも、エンコード処理は1系統のみ行われ負荷の増大を防ぎます。
