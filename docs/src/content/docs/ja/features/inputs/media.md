---
title: 動画、静止画
description: 動画ファイルと静止画の入力
---

StillとVideoのInputは、ファイルパスと設定をセッションに持ちます。ディスク上にそのファイルがあるとき、Mixerはそれを読みます。

ファイルが無いときは、Inputは無効のままセッションに残ります。パス、クロップ、音声、再生の設定は保存時の値です。セッションを開くと、該当Inputを同じダイアログに列挙します。「フォルダから再リンク…」は検索ディレクトリを選び、ファイル名が1件だけ見つかったInputへそのパスを書き戻します。0件または複数件の名前は、保存されているパスのままです。「ファイルを選ぶ…」はStillまたはVideoの1件へファイルを指定します（無効Inputのダイアログでは行をダブルクリックしても同じです）。「Explorerで開く」（macOSはFinder）は、保存されているファイルまたはそのフォルダを開きます。

GUIの「前回」は、最近使ったセッションのうち存在するファイルを、現在のドキュメントとして開きます。書き出し（`.eivzx`）を開くときは、メディアの展開先と作業用`.eivz`の保存先を尋ねます。
