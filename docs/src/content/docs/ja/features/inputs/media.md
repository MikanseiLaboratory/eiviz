静止画（Still）や動画（Video）のInputは、ファイルパスや各種設定（クロップ、ループ再生、音量など）をセッション内に保持します。ファイルがディスク上に存在すれば、Mixerによって読み込まれます。

## ファイルのリンク管理と再リンク

セッション読み込み時に指定パスのファイルが見つからない場合でも、設定は保持されたまま対象のInputは無効（Invalid）状態となり、ファイルが見つからないInputの一覧と再リンク用ダイアログが表示されます。

- **フォルダから再リンク**: 指定したフォルダ内を検索し、同名ファイルが1件のみ見つかった場合にパスを自動で再設定します（見つからない場合や複数見つかった場合は元のパスが維持されます）。
- **ファイルを選択**: ダイアログ上の行をダブルクリックするか「ファイルを選択」から個別に新しいファイルを指定します。
- **エクスプローラー（macOSではFinder）で開く**: 保存されているファイルまたはその親ディレクトリをOSのファイルマネージャーで開いて確認できます。

## ポータブルセッション（.eivzx）

メディアファイルを同梱したアーカイブ形式（`.eivzx`）でエクスポートすることで、別PCへ移行した際のリンク切れを防げます。`.eivzx`を開く際は、メディアファイルの展開先フォルダを指定して作業用セッション（`.eivz`）として展開します。
