---
title: 動画、静止画
description: 動画ファイルと静止画の入力
---

StillとVideoのInputは、ファイルパスと設定をセッションに持ちます。ディスク上にそのファイルがあるとき、Mixerはそれを読みます。

ファイルが無いときは、Inputは無効のままセッションに残ります。パス、クロップ、音声、再生の設定は保存時の値です。Input一覧の「メディアを再リンク…」で検索ディレクトリを選びます。ファイル名が1件だけ見つかったInputへ、そのパスを書き戻します。0件または複数件の名前は、保存されているパスのままです。

GUIの「前回」は、最近使ったセッションのうち存在するファイルを、現在のドキュメントとして開きます。
