静止画（Still）や動画（Video）のInputは、ファイルパスや各種パラメータ（クロップ、ループ再生、音声ボリューム等）をセッション内に保持します。

## ファイルのリンク管理と再リンク

セッション読み込み時に指定パスのファイルが見つからない場合、対象のInputは無効状態として保持され、再リンク用のダイアログが表示されます。

- **フォルダから再リンク**: 指定したディレクトリ内を再帰的に検索し、同名ファイルが存在する場合に自動でパスを再設定します。
- **ファイルを選択**: ダイアログ上の行をダブルクリックするか「ファイルを選択」から個別に新しいファイルを指定します。
- **エクスプローラー/Finderで開く**: 保存されている設定パスまたは親ディレクトリをOSのファイルマネージャーで開いて確認できます。

## ポータブルセッション（.eivzx）

メディアファイルを同梱したアーカイブ形式（`.eivzx`）でエクスポートすることで、別PCへ移行した際のリンク切れを防ぐことができます。`.eivzx`を開く際は、メディアファイルの展開先フォルダを指定して作業用セッション（`.eivz`）として展開します。
