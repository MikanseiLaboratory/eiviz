---
title: NDI / OMT Capture
description: NDIおよびOMTからの映像入力
---

ローカルネットワーク上のNDIまたはOMT（OpenMediaTransport）ソースを受信し、Inputとして取り込みます。

## デコード方式

- **NDI**: CPUでパケットを受信・デコードし、合成用にGPUへアップロードします。
- **OMT**: 受信時のデコード処理をCPUまたはGPUから選択できます（既定: CPU推奨）。
  - **CPU（推奨）**: 標準のデコーダーです。カメラ映像やメインソースなど、品質重視の入力に適しています。
  - **GPU**: デコード処理をGPU側で完結させ、CPU負荷を軽減する補助デコーダーです。Multiview監視などの補助用途に適しています。

## ジッターバッファと帯域制御

- **フレームバッファ（1〜8フレーム）**: ネットワークのパケット揺らぎ（ジッター）を吸収し、安定したフレームレートを維持します。
- **解像度要求（Quality）**: 送信元に対して要求する画質レベルを制御できます。非オンエア時はプレビュー解像度（1/8デコード）へ要求を自動で下げ、ネットワーク帯域を節約できます。
