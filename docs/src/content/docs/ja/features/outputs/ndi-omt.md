---
title: NDI / OMT
description: NDIおよびOMTへの出力
---

Mixing UnitのProgramや指定したソースを、NDIまたはOMT（OpenMediaTransport）を用いてローカルネットワークへ送出します。

## エンコード方式

- **NDI**: CPUベースでエンコードを行い、共通メディアクロックに従って安定したフレームレートで送出します。
- **OMT**: エンコード方式をCPUまたはGPUから選択できます（既定: CPU推奨）。
  - **CPU（推奨）**: 映像本線や番組送出に適した高品位なエンコードを行います。
  - **GPU**: GPU側で圧縮を完結させ、CPU負荷を軽減します。マルチビューなどの監視用送出に適しています。

## 配信効率とスレッド管理

- **独立スレッド配信**: 各出力系統には専用のスレッドが割り当てられ、ネットワーク遅延や負荷が他の配信系統やメインの映像合成に影響を与えません。
- **効率的なマルチキャスト配信**: OMTでは1系統のOutputに対して複数の受信クライアントが存在する場合でもエンコードは1回のみ実行され、生成されたストリームを効率的に分配します。
- **アイドル時のエンコード抑制**: OMT出力では、受信クライアントが0台のときにエンコード処理を自動停止してマシンリソースを節約できます（設定で常時エンコードへ変更可能）。

## 音声のルーティング

映像と同時に送出する音声は、Mixing UnitのMU BusまたはNoneです。内部の48 kHzオーディオグラフでミックスされたPCMが映像と同期して送信されます。Multiview選択時は音声なし固定です。
