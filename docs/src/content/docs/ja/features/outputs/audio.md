eiviz内部のオーディオ処理は48 kHzステレオで動作します。

## モニターとレベル調整

メイン画面下部の音声ミキサーバーには、各入力のPost（フェーダー・ミュート適用後）レベルメーターが表示されます。

- 各チャンネルストリップをダブルクリックするか歯車アイコンをクリックすると、詳細設定ウィンドウが開きます。
- 詳細ウィンドウではPre（入力生レベル）とPost（出力レベル）の両方を確認でき、フェーダーやEQ、ルーティング先バスを設定できます。

## 音声入力（Audio Input）

マイク音声やアプリケーション音声のループバックは、Input一覧から「Audio」として追加します。

- **Windows**:
  - マイク・ライン入力およびデバイスループバック: WASAPI共有モードを使用します。
  - アプリケーション音声（Application Audio）: 指定プロセスの音声出力を直接キャプチャします。
  - ASIO入力: ASIO対応オーディオインターフェースの任意チャンネル（L/R）を直接入力として割り当てられます。
- **macOS**:
  - Core Audio経由でのマイクおよびライン入力に対応しています（プロセス単位のキャプチャは未対応）。

## 音声出力（デバイス出力とネットワーク送出）

- **デバイス出力**: [設定](/eiviz/ja/introduction/settings/)ウィンドウの「音声AUX」から、Master/Headphone/AUXバスをWASAPI共有またはASIO出力デバイスへ割り当てます。
- **ネットワーク送出（OMT/NDI）**: 映像出力とは独立したPCMストリームとして送信されるため、映像エンコードの負荷に関わらず音途切れのない低遅延伝送を維持します。
