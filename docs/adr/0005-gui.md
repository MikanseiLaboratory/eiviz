# ADR-0005 GUI

- Status: Accepted
- Date: 2026-08-23

## Context

映像 preview を同一 GPU device で表示したい。iced 0.14 は wgpu 27、Slint wgpu は unstable かつライセンス選択制。

## Decision

egui/eframe 0.32.3 + wgpu 24 を Presentation に採用する。GUI は Project を直接 mutate せず Command を発行する。preview は latest-wins スロット。

## Consequences

カスタムウィジェットは標準 egui 上に構築する。wgpu 29 へ上げる場合は gpu-video と同時に行う。
