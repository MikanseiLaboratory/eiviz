# ADR-0005 GUI

- Status: Accepted
- Date: 2026-08-23

## Context

映像 preview を同一 GPU device で表示したい。iced 0.14 は wgpu 27、Slint wgpu は unstable かつライセンス選択制。

## Decision

egui/eframe 0.32.3 + wgpu 25.0.2 を Presentation に採用する。GUI は Project を直接 mutate せず Command を発行する。preview は latest-wins スロットで、eframe の Device/Queue と compositor output texture を共有する（ADR-0011）。

## Consequences

カスタムウィジェットは標準 egui 上に構築する。wgpu 世代更新は compositor、
eframe、codec候補を一つの互換単位として行う（ADR-0011/0015）。
